Notas verificadas para esta version:
- `Wokwi-GUEST` es una red abierta para trafico saliente.
- Para acceder desde el navegador a un servidor dentro de Wokwi se requiere Private IoT Gateway / port forwarding.
- MicroPython soporta STA y AP; esta sesion usa STA como camino principal en hardware real.
